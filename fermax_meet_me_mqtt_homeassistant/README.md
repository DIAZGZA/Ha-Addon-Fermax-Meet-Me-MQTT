# Fermax Meet Me MQTT Home Assistant Add-on

Este es el esqueleto estructurado listo para usar como Add-on local en Home Assistant.

## Instrucciones:
1. Reemplaza el archivo `fermaxalarmserver.py` de esta carpeta con tu script original.
2. Copia la carpeta entera `fermax_meet_me_mqtt` dentro del directorio `/addons/` de tu Home Assistant.
3. Ve a la Tienda de Add-ons, recarga/busca actualizaciones e instalalo desde la seccion local.
